# 박물관 웹사이트

전시 정보와 문화행사, 층별 안내, 뮤지엄 굿즈를 한곳에서 확인할 수 있도록 제작한 박물관 웹사이트입니다.  
HTML, CSS, JavaScript를 기반으로 여러 페이지를 구성하고, 슬라이드와 모달 등 사용자 상호작용을 직접 구현했습니다.

> 개인 학습용으로 제작한 비상업적 프로젝트입니다.

## 주요 기능

### 스크롤 반응형 헤더

- 스크롤 위치가 80px을 넘으면 헤더에 별도 클래스를 적용합니다.
- 메뉴의 크기와 여백을 변경해 콘텐츠 영역을 더 넓게 사용할 수 있도록 구성했습니다.

### 전시·문화행사 슬라이드

- 이전·다음 버튼과 포스터 클릭으로 슬라이드를 이동할 수 있습니다.
- 현재, 이전, 다음 포스터의 클래스를 교체하여 화면 전환을 구현했습니다.

### 층별 안내 모달

- 각 층의 `지도보기` 버튼에 저장된 이미지 경로를 읽어 모달에 표시합니다.
- 하나의 모달을 재사용해 층별 안내 이미지를 동적으로 교체합니다.

### 굿즈 페이지

- 메인 배너 자동 재생과 재생·일시정지 기능을 구현했습니다.
- 문구, 신상품, 베스트 상품을 각각 다른 방식의 슬라이드로 구성했습니다.
- 현재 슬라이드 번호와 진행 상태를 화면에 표시합니다.

## 페이지 구성

```text
zs_web_1/
├── index.html              # 메인 페이지
├── pages/
│   ├── information.html    # 관람 정보
│   ├── history.html        # 층별 전시 안내
│   ├── concert.html        # 문화행사
│   └── goods.html          # 뮤지엄 굿즈
├── css/                    # 페이지별 스타일
├── js/                     # 지도 모달 스크립트
├── image/                  # 이미지와 아이콘
├── style.css               # 메인 스타일
└── script.js               # 공통 인터랙션과 슬라이드
```

## 실행 방법

별도의 설치 과정 없이 저장소를 내려받은 후 `index.html`을 브라우저에서 열면 실행할 수 있습니다.

```bash
git clone https://github.com/zlse226/zs_web_1.git
cd zs_web_1
```

## 구현하며 배운 점

- DOM 탐색과 이벤트 리스너를 이용한 화면 상태 변경
- `classList`를 활용한 슬라이드 상태 관리
- `data-*` 속성을 이용한 모달 콘텐츠 교체
- `setInterval`과 인덱스를 이용한 자동 슬라이드 제어
- 여러 페이지에서 공통 레이아웃과 스타일을 유지하는 방법
